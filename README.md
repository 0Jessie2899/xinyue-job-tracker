# Jessie的秋招台账

一个可直接部署到 GitHub Pages 的个人秋招记录网站。纯静态，无框架、无构建步骤。

## 数据说明

网站首次打开是一份**空白台账**，所有记录由你自己录入。数据保存在当前浏览器的 `localStorage` 中，**不会自动同步到其他电脑或浏览器，也不会上传到任何服务器**。建议定期点击页面底部的「导出数据备份」。

### 数据迁移

如果你之前用过带初始数据的旧版本，**请先打开旧版网站点击「导出数据备份」存下 JSON**，再部署本版本，然后用「导入备份」恢复 —— 已有记录一条都不会丢。

## 使用方式

### 记录与关联

网站支持新增、编辑和删除岗位，记录投递日期、岗位要求、当前进度、节点时间、面试信息和期望值等内容。表单会根据你的选择自动联动：

- 选择「待测评、待 AI 面、待一面、待二面、待终面、待 HR 面、业务面」时，对应时间**必填**，该事项会自动进入求职看板，并按时间先后排序。
- 选择「已通过」类状态（如测评通过、一面通过）时，会**自动带出可选的下一节点**；选定后保存即自动推进到该状态，并把上一节点的时间存入节点记录。
- 标记「是否收到面试 = 是」时，网上面试信息必填。
- 选择「挂」类状态或「已放弃 / 流程终止」时，需要填写原因，便于后续复盘。
- 节点时间不能早于投递日期，也不能早于上一个已记录的节点。

待投递目标使用独立的精简表单，投递后可一键「转为已投递」。

### 查看与筛选

- 在投递记录里，点击公司名称后面的 **ⓘ 图标**可展开该岗位的完整信息卡片（含 JD、面经、投递规则、经历匹配、节点记录等），无需进入编辑。
- 求职看板支持「近 7 天 / 近 30 天 / 全部」切换，统计卡片、流程分布与近期事项会随之变化。

### AI 素材生成

AI 是**按需触发**的，不会打扰每条素材的常规编辑：

- 在「面试准备 → 新增 / 编辑素材」的**内容框右下角有一个 🐱 猫咪图标**（炸弹本喵，已抠掉白底），点开即是 AI 智能生成界面：上方输入描述，下方实时生成，满意后点「应用到当前素材」即可把结果填回编辑框（也可先「复制结果」再自己贴）。
- **已配置 API Key**：直接调用你选择的大模型生成素材。
- **未配置 API Key**：自动降级为「复制提示词」—— 把拼好的提示词复制到剪贴板，粘贴到 ChatGPT、豆包等任意外部 AI 即可，功能不打折。
- 生成类型跟随你正在编辑的素材分类（经历打磨 / 常见问题 / 自我介绍）；可勾选「关联岗位」自动带入该岗位 JD。

Key 的配置入口在左侧 / 底部的 **「05 AI 配置」** 板块：填写服务商、Base URL、模型名和 API Key。预置了 DeepSeek、智谱 GLM、Moonshot、阿里百炼、硅基流动，均使用 OpenAI 兼容的 `/chat/completions` 接口，也可选「自定义」填写任意兼容服务。

为防止旁人偷看，**API Key 在保存后只以脱敏形式展示（`****末4位`）**，原文仅存于本机 `localStorage`，永远不会回填到输入框里；想替换时直接输入新值再保存即可，留空表示不改动。

## GitHub Pages 部署

1. 将本项目全部文件（包括 `assets` 文件夹）上传到 GitHub 仓库的 `main` 分支根目录。
2. 打开仓库的 `Settings → Pages`。
3. 在 `Build and deployment` 中选择 `GitHub Actions`。
4. 等待 `Deploy GitHub Pages` 工作流完成。

## 隐私提醒

- 台账数据只存在你自己的浏览器里，不在仓库中、不上传。
- **API Key 保存在本机浏览器的 `localStorage`（键名 `xinyue-job-tracker-ai`），不会写入导出的备份文件。** 已保存的 Key 在 AI 配置页只以 `****末4位` 的脱敏形式回显，原文永不返回输入框。但公开页面上的 JavaScript 可以读取它，共用电脑或恶意浏览器扩展仍有泄露风险。建议填写额度较小的专用 Key，不用时在「05 AI 配置」板块中点「清除 Key」。
- 浏览器直连模型接口依赖服务商允许跨域（CORS）。若调用失败，页面会提示错误码并自动切回提示词模式。预置服务商的接口策略可能变动，请以各家官方文档为准。
- GitHub Pages 页面通常可被公开访问，任何拿到网址的人都能打开。当前版本不再包含任何初始求职数据。
