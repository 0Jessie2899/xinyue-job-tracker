# 熊心悦的秋招台账

一个可直接部署到 GitHub Pages 的个人秋招记录网站。

## 已导入的数据

- 13 条实际投递记录
- 22 个待投递目标
- 6 条经历打磨素材
- 5 条常见面试问题

## 使用方式

网站支持新增、编辑和删除岗位，记录投递日期、岗位要求、投递状态、测评截止日期、面试信息、期望值等内容。当前进度选择“测评”时，测评截止日期为必填项。

数据保存在当前浏览器的 `localStorage` 中，不会自动同步到其他电脑或浏览器。建议在网站底部定期点击“导出数据备份”。

## GitHub Pages 部署

1. 将本项目全部文件上传到 GitHub 仓库的 `main` 分支。
2. 打开仓库的 `Settings → Pages`。
3. 在 `Build and deployment` 中选择 `GitHub Actions`。
4. 等待 `Deploy GitHub Pages` 工作流完成。

## 隐私提醒

GitHub Pages 页面通常可被公开访问，仓库中的 `tracker-source.json` 也包含初始求职记录。请确认其中没有不希望公开的信息后再发布。
